# Firefly 管理后台运行状态中心（开发版）

路径：`/admin/system/`。该路径及 `/api/admin/system-health/` 继承现有后台会话认证，仅已登录管理员可以访问。前台博客的 HTML/CSS/主题/文章渲染保持不变。

## 界面功能

- 默认读取**已配置/未配置**：管理员登录 KV 与密码、GitHub 令牌、私人草稿后端类型（KV/D1）、KV 绑定、D1 绑定、R2 备份绑定、图床 Token、迁移写入冻结模式。
- 点击“测试各服务连通性”后执行只读测试：
  - Cloudflare KV 列表读取
  - Cloudflare R2 备份列表读取
  - D1 草稿表 `SELECT COUNT(*)`（只检查数据库表可访问，不返回稿件数量）
  - GitHub 仓库 GET 可访问性
- 响应只含布尔状态、公开的后端模式（kv/d1）、连通性结果 `ok / failed / not_configured` 和中文配置提示。

## 安全

- 不返回 Token、管理员密码、数据库对象、Namespace ID、Bucket 名称、任何 Markdown 正文或凭据相关的错误细节。
- 只允许 GET，`cache-control: private, no-store`。
- 连接测试只做只读操作，不会创建、覆盖或删除文件、草稿、历史版本或数据库记录。
- 不会据此自动合并 PR，也不会修改生产 Cloudflare 配置。
- 任何“已配置”只说明运行时能找到相应绑定；真正写入/删除/恢复能力仍需专门端到端联调。

## 上线检查

- [ ] 登录和退出后路由被保护
- [ ] 缺少配置时提示能看懂、密钥永不暴露
- [ ] 测试按钮手动触发只读请求，超时或失败不会改变文章
- [ ] KV、D1、R2、GitHub 在预览 Worker 的测试结果可信
- [ ] 验证前台页面、导航、主题、文章均未改变

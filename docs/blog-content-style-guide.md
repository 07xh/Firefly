# 博客课程内容与文章规范（2026-11-02）

本轮仅修改用户勾选的 P1/P2 内容，不修改英语考试评分、f-string 事实校对或访问密码相关 P0 工作。

## 分类与系列

- 主分类统一使用 `Python`、`工程制图`、`英语`、`军事理论`。
- 正文语种统一 `lang: zh-CN`。
- Python 系列：`Python·零基础系统课`，使用按知识依赖排列的 `seriesOrder`。
- 工程制图系列：`工程制图·从投影到解题`，按原理→图线→组合体→尺寸→几何逻辑排序。
- 标签优先从既有统一词表选择，避免 `Python`、`python` 和 `Python基础` 等多种拼法。

## URL 与标题

现有 `/posts/Python2/` 和 `/posts/my-post/` 已可能被引用，本轮保留 URL，不直接重命名以免造成 404。新文章一律使用英文小写的 kebab-case 文件名/URL，描述具体主题。将旧 URL 迁移到新 URL 必须事先加入可验证的永久重定向和链接检查。

文章页布局提供唯一的隐藏 H1，Markdown 正文避免再次输出重复标题；正文从 H2 起组织章节，子主题采用 H3 / H4。文章标题、简介、分类、日期和系列信息填写于 frontmatter。

## Python 文章门禁

每篇至少包含：适用前置知识、概念、逐行可运行代码、预期输出、错误示例、边界和练习；不要跳过先修知识。每个代码片段必须实际运行验证并注明 Python 版本前提，禁止把未经运行的输出当成证据。

## 工程制图插图门禁

插图应包含：第一角法方向约定、几何尺寸、来源视图、线型图例，以及重要点/区间标签；矢量 SVG 可在 Git 中追踪源尺寸。每张题图区分“教学自拟例子”与“教材原题”。插图须按真实空间几何、投影、遮挡和尺寸复核；未核对的教材题不能宣称标准答案。

## 手机阅读验收

在 360px、390px、768px、桌面宽度检查：代码块滚动不撑宽、表格滚动、图可放大、正文无横向溢出、系列导航标题可读、折叠答案可键盘访问，以及暗色主题和减少动态效果。正式部署前运行 `pnpm check`、`pnpm build` 和实际页面截图测试。

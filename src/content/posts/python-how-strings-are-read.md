# Python 到底怎样读懂字符串？从引号、变量到 f-string 花括号的运行原理

你可能已经会写：

```python
name = "小明"
print(f"你好，{name}")
```

**运行结果：**

```text
你好，小明
```

但仔细想想，问题其实不少：

- `name` 为什么会变成“小明”？是不是 Python 看见名字就会替换？
- `"你好，{name}"` 的花括号为什么不输出，里面的 `name` 却会变成变量的值？
- 为什么删掉前面的 `f`，花括号又会原样显示？
- `print("你好，", name)` 明明没有 `f`，为什么也会输出“小明”？
- 为什么 `f"{score + 5}"` 甚至能计算表达式？Python 怎么知道哪些是文字、哪些需要计算？

这篇文章不只是教“怎样套公式”，而是带你理解**Python 读取和解释代码的规则**。从一个普通字符串出发，逐步走到 f-string 的内部工作过程。重点是**先理解为什么，再记住怎么写**。

> **先说明：** 这里的“读取”主要指 Python 如何识别和求值代码，并不是从文件中读取数据的 `open()`，也不是从键盘输入的 `input()`。文末会顺便说明三者的区别。

## 一、先别急着看 f-string：Python 怎么分清文字和变量？

### 1. 看起来一样的字母，为什么会输出不同结果？

```python
name = "小明"

print(name)
print("name")
```

**运行结果：**

```text
小明
name
```

逐行理解：

1. `name = "小明"`：创建一个字符串值 `"小明"`，并让变量名 `name` 引用它。
2. `print(name)`：括号里是**变量表达式**，Python 查找 `name` 对应的值，得到 `"小明"`，再输出。
3. `print("name")`：括号里是**字符串字面量**，代表四个普通英文字母，不是去找同名变量。

这就解释了最基础的区别：**同样写着 `name`，有没有引号，会决定 Python 把它当成变量名还是字符串内容。**

| 代码 | Python 如何理解 | 输出 |
| --- | --- | --- |
| `print(name)` | 读取变量 `name` 的值 | `小明` |
| `print("name")` | 输出字符串中的文字 | `name` |
| `print("小明")` | 输出给定的文字 | `小明` |

### 2. 引号有什么作用？为什么需要它？

假如你直接写：

```text
name = 小明
```

在这里，“小明”没有引号。Python 会尝试把它当作**一个名称**来查找。如果这个名称没有定义，通常会报 `NameError`。

而这样才是把文字保存下来：

```python
name = "小明"
print(name)
```

**运行结果：**

```text
小明
```

引号像是在告诉 Python：“**这一段是字符串内容，而不是等待查找的变量名。**”

单引号 `'...'`、双引号 `"..."` 都能表示普通字符串。初学时推荐统一使用其中一种，注意前后配对。

### 3. 什么叫“读取变量”？是不是把名字印在屏幕上？

不是。变量可以先理解成**一个用于找到某个值的名称**：

```python
score = 92
print(score)

score = 96
print(score)
```

**运行结果：**

```text
92
96
```

`print(score)` 在每次执行时，会使用 **当时** `score` 对应的值，而不是在你写下代码时提前把 `score` 永久换成 `92`。

这个区别对于理解 f-string 至关重要。

## 二、`print()` 为什么可以把文字和变量一起输出？

先看两种相似的写法：

```python
name = "小明"

print("你好，", name)
print("你好，" + name)
```

**运行结果：**

```text
你好， 小明
你好，小明
```

你会发现：第一行多出了一个空格，第二行没有。

### 1. `print("你好，", name)` 中的逗号在做什么？

把这行拆成几个部分：

| 部分 | 含义 |
| --- | --- |
| `print` | Python 的输出函数 |
| `( ... )` | 调用函数并传入参数 |
| `"你好，"` | 第一个参数：普通字符串 |
| `,` | 分隔两个参数 |
| `name` | 第二个参数：变量表达式 |

执行时，Python 分别处理两个参数：

1. 第一个参数已经是字符串 `"你好，"`。
2. 第二个参数 `name` 被求值，得到 `"小明"`。
3. `print()` 接收到两个值，把它们显示出来。

`print()` 默认使用**一个空格**分隔多个参数，所以输出 `你好， 小明`。

**注意：不是引号里的内容自动识别了外面的变量。这里是 `print()` 接收了两个独立参数。**

### 2. 想取消参数之间的空格，该怎么做？

可以使用 `sep` 参数：

```python
name = "小明"

print("你好，", name, sep="")
print("姓名", name, sep="：")
```

**运行结果：**

```text
你好，小明
姓名：小明
```

`sep=""` 表示参数之间不加入分隔字符；`sep="："` 表示用中文冒号分隔。

这说明输出规则是 `print()` 自己规定的，而不是靠猜测文字和变量之间的关系。

### 3. `+` 又为什么能把它们连起来？

```python
name = "小明"
message = "你好，" + name

print(message)
```

**运行结果：**

```text
你好，小明
```

在这里，`+` 用于**拼接两个字符串**：

- 左边是 `"你好，"`。
- 右边 `name` 求值得到 `"小明"`。
- 拼接后得到新的字符串 `"你好，小明"`。

不过要小心数据类型：

```python
age = 18
print("年龄：" + str(age))
```

**运行结果：**

```text
年龄：18
```

`str(age)` 先把整数 18 转成字符串 `"18"`，然后才可以和另一段字符串拼接。直接写 `"年龄：" + age` 会报 `TypeError`。

## 三、为什么需要 f-string？它解决了什么问题？

现在想输出“姓名：小明，成绩：92分”。

不使用 f-string，可以这样写：

```python
name = "小明"
score = 92

print("姓名：", name, "，成绩：", score, "分", sep="")
```

**运行结果：**

```text
姓名：小明，成绩：92分
```

这段代码没错，但文字被拆成了多个参数，稍微长一点就不容易阅读。

用 f-string 可以把**句子保留为一段整体**，再指出哪些位置要填入计算结果：

```python
name = "小明"
score = 92

print(f"姓名：{name}，成绩：{score}分")
```

**运行结果：**

```text
姓名：小明，成绩：92分
```

f-string 是 Python 从 **3.6** 开始支持的语法，英文全称是 *formatted string literal*（格式化字符串字面量）。

你可以把它理解成“**字符串模板 + 需要计算的表达式**”，但它不是普通字符串上的自动查找替换功能，而是 Python 语言专门规定的一种**字符串表达式语法**。

## 四、把 `f"你好，{name}"` 拆开：每个字符负责什么？

先看这行：

```python
name = "小明"
message = f"你好，{name}"

print(message)
```

**运行结果：**

```text
你好，小明
```

可以按下面的方式理解：

| 片段 | 它负责的事情 |
| --- | --- |
| `f` | 告诉 Python：后面的字符串使用 f-string 规则 |
| `"` | 字符串内容开始 |
| `你好，` | 普通文字，保留到结果中 |
| `{` | 开始一个**替换字段** |
| `name` | 需要求值的表达式：读取变量的值 |
| `}` | 结束这个替换字段 |
| `"` | 字符串内容结束 |

### 1. 为什么花括号里的 `name` 会得到变量的值？

因为 `f` 改变了这段字符串的语法规则：在 f-string 的普通文字部分，单层花括号 `{...}` 用来标记**需要求值的表达式**。

当 Python 执行到这行时：

1. 保留普通文字 `"你好，"`。
2. 计算 `name`，得到 `"小明"`。
3. 把这个值转换成适合插入的文字。
4. 拼合为完整字符串 `"你好，小明"`。
5. 将新字符串交给变量 `message`。

这里的“替换”是帮助理解的形象说法。**准确地说，Python 会根据 f-string 语法构造并计算一个字符串表达式。**

### 2. 为什么最终不输出花括号？

因为在 f-string 中，单层 `{` 和 `}` 的任务是**标记替换字段的边界**，它们是语法标记，不属于要保留的普通文字。

看这个对比：

```python
name = "小明"

print("你好，{name}")
print(f"你好，{name}")
```

**运行结果：**

```text
你好，{name}
你好，小明
```

第一行：没有 `f`，`{name}` 只是普通字符串里的六个字符，会原样输出。

第二行：有 `f`，花括号变成替换字段的标记；Python 计算其中的 `name`，最终不保留这对标记。

> **本节关键：** 不是 `print()` 把花括号删掉了。`print()` 接收到的字符串本来就已经是 `"你好，小明"`；花括号的特殊含义发生在**f-string 求值时**。

### 3. `f` 应该放在哪儿？

`f` 是**字符串开头的前缀**，必须紧贴开头引号：

```python
name = "小明"

print(f"你好，{name}")
print(f'你好，{name}')
```

**运行结果：**

```text
你好，小明
你好，小明
```

不要把 `f` 放到右引号后，也不要随意把它与开头引号分开。它并不是普通意义上“写在引号后的变量”。

## 五、Python 怎么知道只计算花括号里面，而不计算外面的文字？

这是整个问题最核心的一部分。

### 1. 普通文字与表达式有不同的身份

```python
name = "小明"
score = 92

message = f"你好，{name}。你的分数是{score}。"
print(message)
```

**运行结果：**

```text
你好，小明。你的分数是92。
```

把 f-string 想成五段：

| 先后顺序 | 片段 | Python 的处理 |
| --- | --- | --- |
| ① | `你好，` | 保留文字 |
| ② | `{name}` | 读取变量 `name` 的值 |
| ③ | `。你的分数是` | 保留文字 |
| ④ | `{score}` | 读取变量 `score` 的值 |
| ⑤ | `。` | 保留文字 |

最终把这些片段的内容连在一起，得到完整的字符串。

**规则不是“遇到一个名字就替换”，而是“在 f-string 的替换字段内计算表达式，外面的内容按普通文字处理”。**

### 2. Python 是什么时候识别这些结构的？

为了入门，可以分成三个阶段：

**阶段一：分析源码结构。** Python 在处理源代码时，识别 `f"..."` 是一种 f-string，并区分普通文字和花括号中的表达式。表达式仍然要符合 Python 语法；括号、引号是否配对，也会在这一阶段受到检查。

**阶段二：程序实际执行。** 当运行到这条 f-string 表达式时，Python 计算替换字段中的变量、加法或函数调用，使用它们**当时**的值。然后依据格式规则生成字符串。

**阶段三：进行输出（如果调用了 `print`）。** 得到的字符串才被传给 `print()`，打印到屏幕上。

这只是帮助初学者理解的简化流程。更准确的词法、语法分析方式会因 Python 实现和版本不同而有细节差异，但**普通文字与替换字段的区别是语言规定的**。

### 3. 验证：变量后来变了，f-string 会怎样？

```python
name = "小明"
print(f"你好，{name}")

name = "小红"
print(f"你好，{name}")
```

**运行结果：**

```text
你好，小明
你好，小红
```

因为这两次是**分别求值的两条 f-string 表达式**，所以每次使用当前的变量值。

但如果先把结果保存下来：

```python
name = "小明"
message = f"你好，{name}"

name = "小红"
print(message)
```

**运行结果：**

```text
你好，小明
```

`message` 保存的是当时已经形成的字符串 `"你好，小明"`，**不是一个以后会随着 `name` 自动变化的模板**。

这能帮助你区分：f-string 的求值是动态的，但**已经生成的普通字符串不会自动更新**。

## 六、花括号里不只是变量：为什么还可以计算加法、取索引？

因为 `{...}` 内部接受的是**Python 表达式**。变量名只是最简单的一种表达式。

### 1. 直接计算数学表达式

```python
a = 3
b = 5

print(f"相加结果：{a + b}")
print(f"平方结果：{a ** 2}")
```

**运行结果：**

```text
相加结果：8
平方结果：9
```

Python 不会把 `a + b` 当作几个普通字符复制出来，而会按照表达式规则先取变量值、完成运算，再将结果插入文字。

### 2. 读取列表里的某个元素

```python
scores = [88, 92, 76]

print(f"第二次成绩：{scores[1]}")
```

**运行结果：**

```text
第二次成绩：92
```

过程是：

1. 在替换字段内识别 `scores[1]`。
2. 从列表 `scores` 读取索引 1 对应的元素 `92`。
3. 把数字格式化成可放进字符串的文字。
4. 组合得到 `"第二次成绩：92"`。

### 3. 调用字符串方法或函数

```python
name = "python"
scores = [88, 92, 76]

print(f"大写：{name.upper()}")
print(f"成绩个数：{len(scores)}")
```

**运行结果：**

```text
大写：PYTHON
成绩个数：3
```

花括号内的 `name.upper()` 会调用方法，`len(scores)` 会调用函数。**同一个替换字段，不局限于读取一个变量名。**

不过建议初学时不要把复杂计算全部塞进花括号。如果表达式过长，先用变量存储结果，更容易检查：

```python
scores = [88, 92, 76]
average = sum(scores) / len(scores)

print(f"平均分：{average:.1f}")
```

**运行结果：**

```text
平均分：85.3
```

## 七、为什么整数也能放进 f-string？格式说明符又是怎么回事？

你可能已经注意到：

```python
score = 92
print(f"成绩：{score}分")
```

**运行结果：**

```text
成绩：92分
```

`score` 本来是整数，为什么能和普通文字组合？

### 1. 字段求值与格式化是两件事

可以分开看：

1. `score` **求值**，得到数字 `92`。
2. f-string **格式化**这个值，生成用于字符串中的文本 `"92"`。
3. 与前后的文字组合。

默认情况下，数字等对象会按照自己的默认格式显示；这和你手动在 `+` 两边拼接字符串不一样。

### 2. 冒号 `:` 是给格式提供要求

```python
score = 92.567

print(f"原始分数：{score}")
print(f"一位小数：{score:.1f}")
print(f"两位小数：{score:.2f}")
```

**运行结果：**

```text
原始分数：92.567
一位小数：92.6
两位小数：92.57
```

理解 `{score:.2f}`：

| 部分 | 含义 |
| --- | --- |
| `score` | 先计算的表达式 |
| `:` | 开始格式说明 |
| `.2f` | 使用固定小数格式，保留 2 位小数 |

你可以把 `:` 理解为：**前面告诉 Python 取哪个值，后面告诉它要怎样显示这个值。**

更多用法以后可以再学；这一篇先掌握 `{变量}`、`{表达式}` 和 `{数字:.2f}`。

## 八、如果我就是想显示花括号本身，该怎么办？

既然 f-string 把 `{...}` 用作替换字段，那怎么显示真正的 `{` 和 `}` 呢？

### 1. 使用两个花括号来表示一个

```python
print(f"{{name}}")
print(f"{{}}")
```

**运行结果：**

```text
{name}
{}
```

在 f-string 的普通文字部分：

- `{{` 表示显示一个普通左花括号 `{`。
- `}}` 表示显示一个普通右花括号 `}`。

这叫**双花括号转义**。它是 f-string 自己的语法规则，不是 `print()` 的隐藏功能。

### 2. 同时显示花括号和变量值

```python
name = "小明"

print(f"{{{name}}}")
```

**运行结果：**

```text
{小明}
```

可以拆开来看：

1. 开头的 `{{` 表示要显示一个 `{`。
2. 中间的 `{name}` 表示计算并插入 `name` 的值。
3. 最后的 `}}` 表示要显示一个 `}`。

所以它的结果就是**带花括号的小明**。

### 3. 为什么不能随便只写一个花括号？

以下是**错误示意，不要直接当成可以运行的程序**：

```text
print(f"你好，{name")
```

替换字段没有正确闭合，Python 无法完成语法分析，会报 `SyntaxError`。如果想显示普通花括号，应使用双花括号，而不是写一个落单的花括号。

## 九、为什么 `"{name}"`、`f"{name}"`、`"{}".format(name)` 不一样？

三者长得相似，但**所用的规则不同**。

| 写法 | 解释 | 示例结果 |
| --- | --- | --- |
| `"{name}"` | 普通字符串，花括号只是文字 | `{name}` |
| `f"{name}"` | f-string，计算变量 `name` | `小明` |
| `"{}".format(name)` | 调用字符串的 `format` 方法，按字段位置格式化 | `小明` |
| `print("你好", name)` | 把两个参数交给 `print` | `你好 小明` |

### 1. 普通字符串不会自动执行其中的代码

```python
name = "小明"

print("{name}")
print("2 + 3")
```

**运行结果：**

```text
{name}
2 + 3
```

因为普通引号的内容就是文字，它不会扫描里面的名字并偷偷执行。

### 2. `format()` 为什么也能替换花括号？

```python
name = "小明"
age = 18

print("你好，{}".format(name))
print("姓名：{}，年龄：{}".format(name, age))
```

**运行结果：**

```text
你好，小明
姓名：小明，年龄：18
```

`format()` 是**字符串提供的方法**，它会按照格式字符串的占位规则处理文字和传入的参数。它和 f-string 的外观接近，但并不是同一套完整语法。

例如 f-string 可以直接写 `{1 + 2}`，而 `"{}".format(1 + 2)` 是先计算调用参数，再由 `format()` 放进字符串。

> **区分原理：** f-string 是 Python 语言的字符串字面量语法；`str.format()` 是一个方法调用；`print()` 是负责输出参数的函数。**三个不同的机制，可能得到相似的屏幕结果。**

## 十、常见错误：为什么看着像对的代码却不输出预期结果？

### 错误一：忘了写 `f`

```python
name = "小明"

print("你好，{name}")
print(f"你好，{name}")
```

**运行结果：**

```text
你好，{name}
你好，小明
```

普通字符串不把 `{name}` 当成表达式，所以会原样显示。

### 错误二：变量没有定义

**错误示意：**

```text
print(f"你好，{name}")
```

如果当前作用域找不到 `name`，执行时通常会出现 `NameError`。

**正确写法：**

```python
name = "小明"
print(f"你好，{name}")
```

### 错误三：把变量名写在普通字符串中，误以为自动读取

```python
name = "小明"

print("name")
print(name)
```

**运行结果：**

```text
name
小明
```

变量表达式 `name` 与普通字符串 `"name"` 是不同的东西。

### 错误四：认为 f-string 会反复寻找嵌套的变量

```python
age = 18
text = "{age}"

print(f"内容：{text}")
```

**运行结果：**

```text
内容：{age}
```

为什么没有继续把 `{age}` 换成 `18`？

因为 `{text}` 只负责求出变量 `text` 的值。这个值刚好包含字符 `{age}`，但**返回的字符串不会再被当成另一段 f-string 代码重复解析**。

这非常重要：**f-string 不是无限循环的查找替换系统。**

### 错误五：把 f-string 误当作一个会实时更新的容器

```python
score = 80
message = f"成绩：{score}"

score = 90
print(message)
```

**运行结果：**

```text
成绩：80
```

`message` 保存的是最初生成的字符串；修改 `score` 并不会让旧字符串自动重新计算。想看到新分数，需要重新求值一次 f-string。

### 错误六：混淆字符串转义与 f-string 替换字段

```python
name = "小明"

print(f"你好，{name}\n欢迎学习 Python")
```

**运行结果：**

```text
你好，小明
欢迎学习 Python
```

`\n` 是**字符串中的换行转义序列**，`{name}` 是**f-string 的替换字段**。二者都在影响结果，但机制不同：一个控制特殊字符，一个负责计算表达式并插入文本。

## 十一、别把“读取代码”“读取输入”“输出结果”混在一起

前面一直在说 Python 如何“读懂”字符串；但现实中你还会遇到 `input()`、`print()`、`open()` 等名字。它们的工作完全不同。

| 名称 | 主要做什么 | 例子 |
| --- | --- | --- |
| 解析代码 | 理解源代码的语法结构 | 识别 `f"{name}"` |
| 表达式求值 | 运行时计算变量、函数或运算 | 计算 `name` 或 `2 + 3` |
| `print()` | 把值输出到屏幕等文本流 | `print(name)` |
| `input()` | 从标准输入读取一行文本 | `name = input("姓名：")` |
| `open()` | 打开文件，用于后续读取或写入 | `open("note.txt", encoding="utf-8")` |

### 1. 一个简短的 `input()` 示例

```python
name = input("请输入姓名：")
print(f"你好，{name}")
```

**交互示例（假设输入“小明”）：**

```text
请输入姓名：小明
你好，小明
```

`input()` 把用户输入的一行内容返回为**字符串**；`f"你好，{name}"` 再读取变量 `name` 的值来构造新字符串；`print()` 最后显示它。

这里既有输入，又有表达式求值和输出。它们依靠不同的函数和语言规则完成，不能混为一谈。

### 2. `input()` 读到的数字为什么不能直接做整数运算？

```python
age_text = "18"   # 模拟 input() 读取到的字符串
age = int(age_text)

print(f"明年是{age + 1}岁")
```

**运行结果：**

```text
明年是19岁
```

因为 `input()` 返回的是字符串，即使看起来写着数字，也需要根据用途转换成整数或浮点数。f-string 会把数值格式化成文字，但**不会自动保证你的输入已经是正确的数值类型**。

## 十二、用一张流程表，完整理解 f-string 从源码到输出

来看一个稍复杂、但你已经能理解的例子：

```python
name = "小明"
scores = [88, 92, 76]
average = sum(scores) / len(scores)

message = f"{name}的平均成绩为{average:.1f}分"
print(message)
```

**运行结果：**

```text
小明的平均成绩为85.3分
```

从**概念上**，可以把整条路径分成六步：

| 步骤 | Python 处理的内容 | 得到的结果 |
| --- | --- | --- |
| ① | 识别 `f"..."` | 知道这是一条 f-string 表达式 |
| ② | 区分普通文字与替换字段 | 找到 `{name}`、`{average:.1f}` |
| ③ | 对字段求值 | 得到 `"小明"`、约 `85.333...` |
| ④ | 按格式生成文字 | `average:.1f` 得到 `85.3` |
| ⑤ | 组合成完整字符串 | `"小明的平均成绩为85.3分"` |
| ⑥ | 将字符串交给 `print()` | 屏幕显示最终文字 |

**花括号没有输出，是因为它们在第②步就被识别为语法边界；真正交给 `print()` 的是已经组合好的字符串。**

### 三个必须能回答的小问题

**问：没有 `f`，是不是也能输出变量？**

能。`print("你好", name)` 让 `print` 接收多个独立参数，不需要 f-string。

**问：为什么 `f"结果：{2 + 3}"` 输出数字 5，而不是文字 `2 + 3`？**

因为花括号内是表达式。Python 先计算 `2 + 3`，再把结果插进文字。

**问：如果想打印花括号本身呢？**

在 f-string 的普通文字部分写 `{{`、`}}`，分别表示一个字面上的 `{`、`}`。

## 十三、动手练习：每一道都要说清“为什么”

### 练习 1：有 `f` 和没有 `f`

```python
name = "小明"

print("{name}")
print(f"{name}")
```

猜一猜两行分别输出什么。为什么第一行花括号保留了下来？

<details>
<summary>点击查看练习 1 答案</summary>

```text
{name}
小明
```

第一行是普通字符串，其中花括号只是文字；第二行是 f-string，`{name}` 被作为替换字段求值。

</details>

### 练习 2：先保存，再修改变量

```python
number = 5
message = f"当前数字：{number}"

number = 8
print(message)
print(f"当前数字：{number}")
```

猜输出是否相同，并解释原因。

<details>
<summary>点击查看练习 2 答案</summary>

```text
当前数字：5
当前数字：8
```

`message` 在 `number` 等于 5 时就保存好了字符串。最后一行重新执行 f-string，读取到当前值 8。

</details>

### 练习 3：花括号究竟会不会输出？

```python
name = "小明"

print(f"{{name}}")
print(f"{{{name}}}")
```

<details>
<summary>点击查看练习 3 答案</summary>

```text
{name}
{小明}
```

`{{` 和 `}}` 分别代表要显示的普通花括号；中间单层的 `{name}` 才是真正的替换字段。

</details>

### 练习 4：把一句话写成三种方式

目标输出：

```text
姓名：小明，分数：92
```

分别尝试使用：`print()` 的多个参数、字符串拼接和 f-string。

<details>
<summary>点击查看练习 4 参考答案</summary>

```python
name = "小明"
score = 92

print("姓名：", name, "，分数：", score, sep="")
print("姓名：" + name + "，分数：" + str(score))
print(f"姓名：{name}，分数：{score}")
```

**这三种写法都会输出相同的一句话**，但实现机制不同：多个参数由 `print` 负责分隔，`+` 在两个字符串之间拼接，f-string 根据替换字段求值并格式化。

</details>

## 十四、最后复习：一张表看懂整篇文章

| 你看到的写法 | 真正的机制 | 你应该怎么读 |
| --- | --- | --- |
| `"name"` | 普通字符串字面量 | 原样的文字“name” |
| `name` | 变量表达式 | 查找当前变量的值 |
| `print(name)` | 函数调用 | 求值后输出 |
| `print("你好", name)` | 多个参数的输出 | 分别求值、默认用空格隔开 |
| `"你好，" + name` | 字符串拼接 | 把两个字符串连起来 |
| `"{name}"` | 普通字符串 | 花括号原样保留 |
| `f"{name}"` | f-string 替换字段 | 计算 `name` 并放入文字 |
| `f"{a + b}"` | 表达式求值 | 先做加法再插入结果 |
| `f"{score:.2f}"` | 格式说明 | 以两位小数格式显示 |
| `f"{{name}}"` | 双花括号转义 | 输出字面上的 `{name}` |
| `input("提示：")` | 读取输入 | 返回用户输入的字符串 |

真正值得记住的是：

**引号告诉 Python“这些是文字”；变量名让 Python查找一个值；f-string 前缀告诉 Python“花括号里是要计算的表达式”；`print()` 负责把已经得到的值显示出来。**

所以，`f"你好，{name}"` 并不是 Python “智能猜中你想替换什么”，而是语言设计者**明确规定了这套语法**，Python 按规则识别和执行它。

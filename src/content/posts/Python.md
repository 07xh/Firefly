01 / Python 符号速览

Python 中的符号可以按用途分成几组。先认识下面六个最常见的符号，再逐步理解它们在代码中的作用。

符号| 作用| 最简单的例子
"()"| 函数调用| "print("Hello")"
"[]"| 列表与索引| "scores[0]"
"{}"| 格式化变量| "f"{name}""
"."| 对象访问| "fruits.append("苹果")"
":"| 引出代码块| "if score >= 60:"
"=="| 比较是否相等| "score == 90"

阅读方式： 每个符号都按照“作用 → 示例 → 输出 → 易错点”的顺序介绍。

02 / 三种括号

"()" · 小括号

主要作用：调用函数、组织运算顺序。

print("Hello Python")

result = (2 + 3) * 4
print(result)

运行结果

Hello Python
20

"print()" 用于输出内容；数学表达式中的 "(2 + 3)" 会优先计算。

如果没有小括号，"2 + 3 * 4" 的结果是 "14"，因为乘法优先于加法。

"[]" · 方括号

主要作用：创建列表、读取指定位置的元素。

fruits = ["苹果", "香蕉", "橙子"]

print(fruits[0])
print(fruits[2])

运行结果

苹果
橙子

索引| 元素
"0"| 苹果
"1"| 香蕉
"2"| 橙子

«知识提示
Python 列表索引从 "0" 开始。访问不存在的位置，例如 "fruits[3]"，会产生 "IndexError"。»

"{}" · 花括号

主要作用之一：在 f-string 中插入变量。

name = "数学"
score = 92

print(f"{name}得了{score}分")

运行结果

数学得了92分

这里的 "f" 表示格式化字符串，"{name}" 和 "{score}" 会被对应变量的值替换。

花括号还可以用于字典和集合：

student = {"name": "小明", "score": 92}
numbers = {1, 2, 3}

这些数据结构可以在后续学习中再深入理解。

03 / 点号与标点

"." · 点号

主要作用：访问对象的属性或方法。

fruits = ["苹果"]

fruits.append("香蕉")

print(fruits)

运行结果

['苹果', '香蕉']

可以把 "fruits.append("香蕉")" 理解为：让 "fruits" 这个列表执行“添加元素”的操作。

另一个例子：

message = "hello"
print(message.upper())

运行结果

HELLO

".upper()" 是字符串的方法，可以将英文字母转换成大写。

«记忆技巧
看到 "对象.名称"，先想到“访问这个对象提供的属性或功能”。»

":" · 冒号

主要作用：引出缩进代码块。

score = 85

if score >= 60:
    print("及格")

运行结果

及格

冒号通常出现在 "if"、"for"、"while" 等语句后面。

它还可以用于列表切片：

numbers = [10, 20, 30, 40]
print(numbers[1:3])

运行结果

[20, 30]

这里的 "1:3" 表示从索引 1 开始，到索引 3 之前结束，不包含索引 3。

"," · 逗号

主要作用：分隔多个元素、参数或变量。

print("数学", 92)

运行结果

数学 92

在列表中，逗号用于分隔元素：

scores = [92, 45, 78]

在 "enumerate()" 循环中，逗号可以分隔接收编号和元素的变量：

for number, score in enumerate(scores, start=1):
    print(number, score)

"#" · 井号

主要作用：编写单行注释。

# 判断成绩是否及格
score = 85

if score >= 60:
    print("及格")

注释用于解释代码，不会作为普通 Python 语句执行。

"""" 与 "''" · 引号

主要作用：表示字符串。

name = "Python"
language = 'Python'

print(name)
print(language)

两种写法都可以使用，但开头和结尾的引号必须正确配对。

04 / 赋值与比较

"=" · 赋值

score = 90

这表示把数值 "90" 赋给变量 "score"。

"==" · 比较是否相等

score = 90

print(score == 90)
print(score == 80)

运行结果

True
False

"True" 表示判断成立，"False" 表示判断不成立。

常用比较运算符

符号| 含义| 示例
"=="| 等于| "90 == 90"
"!="| 不等于| "90 != 60"
">"| 大于| "90 > 60"
"<"| 小于| "50 < 60"
">="| 大于等于| "60 >= 60"
"<="| 小于等于| "59 <= 60"

«易错提醒
"=" 是赋值，"==" 才是相等比较。
判断及格应使用 "score >= 60"，因为 60 分也算及格。»

05 / 数学运算符

Python 可以直接进行数学计算。

符号| 作用| 示例| 结果
"+"| 加法| "5 + 2"| "7"
"-"| 减法| "5 - 2"| "3"
"*"| 乘法| "5 * 2"| "10"
"/"| 普通除法| "5 / 2"| "2.5"
"//"| 向下取整除法| "5 // 2"| "2"
"%"| 取余| "5 % 2"| "1"
"**"| 幂运算| "2 ** 3"| "8"

三个容易混淆的运算符

print(10 // 3)
print(10 % 3)
print(2 ** 4)

运行结果

3
1
16

其中：

- "//"：除法后向下取整。
- "%"：获取余数。
- "**"：计算幂。

«边界提醒
"//" 对负数也会向下取整，并非简单去掉小数部分。除数为零时，除法、整除和取余都会报错。»

06 / 其他值得认识的符号

符号或关键字| 作用| 示例
"+="| 增加后赋值| "count += 1"
"-="| 减少后赋值| "count -= 1"
"*="| 乘法后赋值| "count *= 2"
"and"| 两个条件都成立| "a > 0 and b > 0"
"or"| 至少一个条件成立| "a > 0 or b > 0"
"not"| 逻辑取反| "not True"
"in"| 判断成员关系| ""苹果" in fruits"
"\n"| 字符串中的换行符| ""第一行\n第二行""
"\t"| 字符串中的制表符| ""姓名\t成绩""
"@"| 装饰器等用途| "@staticmethod"
"->"| 返回值类型标注| "def get_age() -> int:"

这些符号不需要一次全部记住。遇到实际使用场景时，再逐个深入理解即可。

07 / 综合实战：筛选及格成绩

现在把前面认识的符号放进一个完整的 Python 程序。

任务： 给定五名学生的成绩，只输出及格学生的原始编号与成绩。

Python 代码

scores = [92, 45, 78, 56, 88]

for number, score in enumerate(scores, start=1):
    if score >= 60:
        print(f"第{number}位：{score}分")

运行结果

第1位：92分
第3位：78分
第5位：88分

符号拆解

符号或语法| 作用
"="| 把成绩列表赋给变量
"[]"| 创建列表
"()"| 调用函数
","| 分隔参数和变量
"start=1"| 设置编号起点
":"| 引出缩进代码块
">="| 判断是否及格
"{number}"| 插入学生编号
"{score}"| 插入学生成绩

"enumerate()" 在遍历时同时提供编号和元素，因此跳过不及格成绩后，仍然可以保留学生的原始编号。

08 / 常见错误警示

错误一：混淆 "=" 与 "=="

score = 90    # 赋值
score == 90   # 比较

两者含义不同。

错误二：忘记 f-string 的 "f"

name = "Python"
print("{name}")

输出：

{name}

正确写法：

print(f"{name}")

输出：

Python

错误三：使用中文全角语法标点

错误：

print（"你好"）

正确：

print("你好")

Python 语法中的括号、逗号等符号通常必须使用英文半角形式。

错误四：忽略缩进

错误：

if score >= 60:
print("及格")

正确：

if score >= 60:
    print("及格")

建议按照 PEP 8 规范，使用四个空格作为一级缩进。

错误五：列表索引越界

fruits = ["苹果", "香蕉"]
print(fruits[2])

这个列表只有索引 "0" 和 "1"，因此访问 "fruits[2]" 会产生 "IndexError"。

括号与对象访问

标点与代码结构

"," 数据分隔　·　":" 代码块　·　"#" 注释

赋值与比较

"=" 赋值　·　"==" 相等比较　·　"!=" 不相等　·　">=" 大于等于

数学运算

"+" 加法　·　"-" 减法　·　"*" 乘法　·　"/" 除法　·　"//" 向下取整　·　"%" 取余　·　"**" 幂运算

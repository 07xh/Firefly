# 工程制图的实线和虚线究竟由什么决定？

> **投影重合不等于空间重合。线型不是靠猜位置决定的，而要结合空间几何、观察方向、实体遮挡和工程表达规则。**

学工程制图时，常听到“看得见的画实线，看不见的画虚线”。但真正做题时，难点是：怎么判断是否被挡住？为什么两条空间棱线在一张图上重合？为什么有的地方不画线？

本文从简单的点和棱线出发，不要求先完整想象复杂立体。

## 一、先分清三个视图

采用第一角画法，约定物体左右为 x 方向（向右为正），前后为 y 方向（向后为正），上下为 z 方向（向上为正）。

| 视图 | 观察方向 | 能直接反映 | 丢失的坐标 |
|---|---|---|---|
| 主视图 V | 前向后 | 左右、上下 | y |
| 俯视图 H | 上向下 | 左右、前后 | z |
| 左视图 W | 左向右 | 前后、上下 | x |

第一角画法常见展开位置：主视图上方，俯视图在其下方，左视图在其右侧。按本文坐标和展开约定，左视图图纸左侧对应物体后方，右侧对应前方。

例如：

```text
A = (2, 1, 3)
B = (2, 4, 3)

主视投影：
V(A) = (2, 3)
V(B) = (2, 3)

俯视投影：
H(A) = (2, 1)
H(B) = (2, 4)
```

A、B 是不同空间点，主视图却完全重合，因为主视图不记录前后深度。**二维位置相同，不足以证明空间中是同一个点。**

## 二、空间有线，不等于图纸一定要画线

判断时要分开三个问题：

1. **空间里有什么？** 是真实尖锐棱线、曲面视轮廓，还是作图辅助线？
2. **在这个方向看得见吗？** 是否有不透明实体表面挡住？
3. **图纸应该怎样表达？** 画可见线、不可见线、其他线型，还是不单独画？

通常机械制图中，可见轮廓线、可见棱线画**粗实线**；需要表达的不可见轮廓线、棱线画**细虚线**；轴线、对称中心线常用**细点画线**。尺寸线等也是实线，但不是实体轮廓线。具体线型和优先级以课程采用的制图标准为准。

因此，不是所有实线都是可见棱线，也不是所有被遮住的结构都必须画虚线。

## 三、为什么“更靠前”仍不能直接判虚线？

假设后方有棱线 B，前方有棱线 A。只知道 A 比 B 靠前，仍不能证明 B 被遮挡。

真正需要检查的是：**沿经过 B 投影位置的观察射线，是否先碰到其他不透明实体表面？**

在本文坐标下，主视图某个投影位置 (x,z) 对应的空间直线可写为：

```text
R(t) = (x, t, z)
```

t 表示前后深度。沿从前向后的观察方向，较小的 t 更靠近观察者。但只有当实际表面挡在后方棱线前面，才能判定遮挡。二维图中两条线交叉、一个点比另一个点更靠前，都不能单独替代这一检查。

## 四、例子：长方体两条竖棱，主视图为什么只画一条？

取长方体的前左、后左两条竖棱：

```text
前左竖棱：x = 0，y = 0，0 ≤ z ≤ 4
后左竖棱：x = 0，y = 3，0 ≤ z ≤ 4
```

**第一步，找空间差异。** 两条棱线左右位置、高度范围相同，但前后深度不同，是真正不同的空间棱线。

**第二步，投影到主视图。** 主视图丢失 y，所以两条竖棱都投影到同一条竖线。

**第三步，检查实体遮挡。** 前左竖棱是可见边界；后左竖棱处于长方体后方，被实体挡住。

**第四步，决定画法。** 可见粗实线与不可见细虚线投影重合时，这里以可见轮廓的粗实线表达，不叠画两条线。

换到左视图，观察方向改变，两条棱线的前后位置能分开，可能分别成为左侧面的两条可见边界。**同一空间棱线在不同视图中的可见性可能不同。**

## 五、为什么一条线可能一部分实线、一部分虚线？

假设一条后方横向棱线的中间被前方挡板挡住，而两端没有被挡住。

正确过程是：

1. 找到这条空间线的起点和终点，确认它们属于同一条棱线。
2. 把整条线投影到目标视图。
3. 找出挡板在观察方向上的真实覆盖范围。
4. 求出遮挡开始和结束的位置，把线分成若干段。
5. 分别判断每段是否可见，以及被遮挡段是否需要用虚线表达。

因此可能出现“左段粗实线—中段细虚线—右段粗实线”。

如果线段端点为 P0、P1，可用参数表示线上位置：

```text
L(t) = P0 + t × (P1 - P0)
0 ≤ t ≤ 1
```

t=0 是起点，t=1 是终点。遮挡的参数区间必须根据真实几何关系确定，**不能仅凭两端可见就认定中间也可见**。截交线、相贯线同样需要考虑逐段可见性。

## 六、为什么有的地方不画线？

- **光滑曲面不等于尖锐棱线。** 圆柱侧面没有左右两条真实折角棱线，但特定视图中可以出现两条可见视轮廓线。
- **辅助线不是实体边界。** 45° 转移线、投影联系线用于求点，不应直接当作最终轮廓。
- **不同来源可能投影重合。** 需要按图线优先规则处理，不能把每个来源都叠画出来。
- **有些不可见结构不需要单独表达。** 是否画隐藏线还要看图样目的、标准和其他表达方式。
- **证据不足时不能猜。** 不清楚线的来源、连接或遮挡，就应继续核对。

## 七、不先想象完整立体，怎样判断一条线？

遇到补第三视图、组合体补缺线时，依次问：

**① 它是什么？** 是真实棱线、曲面视轮廓，还是辅助线？

**② 两端在哪里？** 找到真实端点、转折点或交点，不能看到两个二维点就随意相连。

**③ 投影位置在哪里？** 利用“长对正、高平齐、宽相等”确定坐标。主俯对左右，主左对高度，俯左对前后宽度；必要时使用符合第一角画法的 45° 转移线。

**④ 来源对应可靠吗？** 两条投影线重合，不代表来自同一条空间棱线。

**⑤ 当前从哪边看？** 主视从前，俯视从上，左视从左。

**⑥ 有没有表面挡住？** 需要沿观察方向检查实际实体表面，不只比较两个点的前后、上下或左右。

**⑦ 是否需要分段？** 同一条线的遮挡状态可能沿长度变化。

**⑧ 最终怎样表达？** 可见粗实线、需要表达的不可见细虚线、不单独画，或证据不足继续检查。

## 八、为什么三视图有时仍不能唯一确定实体？

对于**已经确认对应关系**的同一个空间点，主视图提供 x、z，俯视图提供 x、y，通常能恢复其三维坐标。但一个实体还包含棱线连接、表面关系和内部结构。

只给三个外轮廓，不给必要的尺寸、隐藏线或剖视信息，不同实体可能具有相同外轮廓。**能恢复某个点，不等于能唯一恢复整个物体。**

## 九、检验一下

```text
C = (3, 2, 1)
D = (3, 5, 1)
```

请判断：C、D 在主视图是否重合？在俯视图是否重合？谁更靠前？能否直接断定经过 D 的棱线一定画虚线？

**答案：** 主视图重合；俯视图不重合；C 更靠前；不能直接断定 D 所在棱线为虚线，因为尚未确认实际遮挡表面，也未确认是否需要单独表达。

## 十、总结

```text
确认空间对象
    ↓
确定观察方向
    ↓
找到投影位置与对应关系
    ↓
检查真实表面遮挡
    ↓
必要时分段
    ↓
应用工程图线表达规则
```

**二维重合说的是投影位置相同；实线、虚线说的是特定视图中的可见性和工程表达。两者有关，却不是同一回事。**

理解这套顺序后，遇到组合体、补第三视图、截交线和相贯线，可以从局部点线关系逐步推理，而不是凭印象猜线。

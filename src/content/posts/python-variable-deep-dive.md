刚学 Python 时，我们经常看到这样的代码：

```python
score = 90
print(score)
```

运行结果：

```text
90
```

看起来非常简单，但里面藏着几个很值得弄明白的问题：

- 为什么 `score` 不加引号会输出 `90`，加上引号却输出文字 `score`？
- 为什么 `a = b` 有时会让两个变量一起变化，有时却不会？
- 为什么 `a == b` 是 `True`，`a is b` 却可能是 `False`？
- 为什么函数里的变量有时能影响函数外的数据？
- 为什么 `a += 1` 和 `a.append(1)` 不是同一种操作？

本文不要求你先学会复杂的计算机原理。我们先从一个能运行的小例子入手，再逐渐理解背后的“**名字 → 对象 → 绑定关系**”。

> **先记住一句话：** 在 Python 中，变量名不是装着数据的盒子。更准确地说，**变量名是一个名字，这个名字绑定到一个对象**。你可以先把“绑定”理解为“把一个名字和某个数据对象关联起来”。

## 一、从 `score = 90` 开始：Python 到底做了什么？

### 1. 先读懂这一行

```python
score = 90
```

不要把它读成数学上的“score 等于 90”，而应该读成：

**把右边计算得到的对象，绑定到左边的名字 `score`。**

可以把这行代码想象成三步：

1. Python 识别左侧要绑定的名字：`score`。
2. Python 计算右侧表达式 `90`，得到一个整数对象。
3. Python 让 `score` 这个名字绑定到该对象。

用示意图表示：

```text
变量名             对象
score  ─────────→  90
```

箭头不是 Python 真正写在内存里的字符，只是帮助理解“名字与对象的关系”。

### 2. 为什么 `print(score)` 能输出 90？

```python
score = 90
print(score)
print("score")
```

输出：

```text
90
score
```

两行 `print` 看起来只差一对引号，Python 的理解却完全不同：

| 写法 | Python 如何理解 | 输出 |
| --- | --- | --- |
| `print(score)` | 读取名字 `score` 当前绑定的对象 | `90` |
| `print("score")` | 读取引号中的字符串字面量 | `score` |
| `print(90)` | 直接使用整数对象 | `90` |

**引号内的普通文字，不会自动替换成同名变量的值。** 这也是为什么下面会出错：

```python
print(total)
```

如果之前没有为 `total` 建立可读取的绑定，就会遇到 `NameError`，因为 Python 找不到这个名字。

### 3. 那么 f-string 为什么能插入变量？

```python
name = "小明"
score = 90

print(f"{name}得了{score}分")
```

输出：

```text
小明得了90分
```

这是因为 `f"..."` 告诉 Python：**这个字符串中，花括号里的内容要当作表达式求值，再格式化并放进结果字符串里。**

这里发生的是：

- `{name}`：读取名字 `name`，得到字符串 `"小明"`；
- `{score}`：读取名字 `score`，得到整数 `90`，再转换成适合显示的文字；
- 花括号是 f-string 的**语法标记**，所以默认不会原样输出。

想输出真正的花括号，可以写双花括号：

```python
score = 90
print(f"{{score}} = {score}")
```

输出：

```text
{score} = 90
```

注意：变量的绑定原理与 f-string 的格式化规则是两回事。f-string **读取并使用**变量，但不会因为读取就修改变量。

## 二、变量可以重新赋值：变的是名字的绑定

```python
score = 90
print(score)

score = 95
print(score)
```

输出：

```text
90
95
```

运行顺序是：

1. 第一行把 `score` 绑定到整数对象 `90`。
2. 第一次 `print` 读取它，输出 `90`。
3. `score = 95` 让名字 `score` 改为绑定到整数对象 `95`。
4. 第二次 `print` 再读取它，输出 `95`。

关键是：**重新赋值并不需要把原来的整数 90“改造成”95。它改变的是名字所绑定的对象。**

### 先算右边，再处理左边

```python
number = 5
number = number + 2
print(number)
```

输出：

```text
7
```

第二行请按这个顺序理解：

1. Python 先读取右侧 `number` 当前的值 `5`；
2. 计算 `5 + 2`，得到 `7`；
3. 把左侧名字 `number` 重新绑定到结果 `7`。

它不是数学方程，也不是在比较两个数是否相等。

| 符号 | 含义 | 例子 |
| --- | --- | --- |
| `=` | 赋值或绑定 | `x = 3` |
| `==` | 比较值是否相等 | `x == 3` |
| `!=` | 比较值是否不相等 | `x != 3` |
| `is` | 比较是否是同一对象 | `a is b` |

其中 `!=` 要写成一个整体；`! =` 不能拆开使用。

## 三、对象是什么？值、类型和身份有什么区别？

前面说“名字绑定对象”，那对象究竟是什么？

对于初学者，可以把对象理解成 Python 在运行时处理的数据实体。例如：

```python
age = 18
name = "小明"
scores = [90, 95, 88]
```

这里的整数、字符串、列表都是对象。对象可以从三个角度观察：

| 角度 | 问的问题 | 查看方式 |
| --- | --- | --- |
| 值（value） | 里面表示什么内容？ | `print(age)` |
| 类型（type） | 这是哪一种对象？ | `type(age)` |
| 身份（identity） | 它是否就是那个同一对象？ | `id(age)` 或 `is` |

```python
age = 18
name = "小明"
scores = [90, 95, 88]

print(type(age))
print(type(name))
print(type(scores))
```

输出：

```text
<class 'int'>
<class 'str'>
<class 'list'>
```

`int` 是整数类型，`str` 是字符串类型，`list` 是列表类型。

### 变量名本身有类型吗？

```python
data = 100
print(type(data))

data = "一百分"
print(type(data))
```

输出：

```text
<class 'int'>
<class 'str'>
```

这里不是名字 `data` 从内部“变成”了字符串，而是它**先绑定整数对象，后绑定字符串对象**。因此更精确的说法是：**对象有类型；同一个变量名可以先后绑定不同类型的对象。**

这种灵活性是 Python 动态类型特征的一部分。但日常编程中，尽量让同一个名字的用途保持稳定，可使代码更容易阅读。

## 四、最容易困惑的地方：`b = a` 并不等于复制对象

### 1. 先看整数

```python
a = 10
b = a

a = 20

print(a)
print(b)
```

输出：

```text
20
10
```

当执行 `b = a` 时，Python 读取 `a` 所绑定的对象，让 `b` 也绑定到它。随后 `a = 20` 只是**改变 `a` 的绑定**，没有改变 `b`。

初始：

```text
a ──┐
    ├────────→ 10
b ──┘
```

重新赋值后：

```text
a ───────────→ 20
b ───────────→ 10
```

### 2. 再看列表：结果完全不同

```python
a = [10, 20]
b = a

a.append(30)

print(a)
print(b)
```

输出：

```text
[10, 20, 30]
[10, 20, 30]
```

为什么 `b` 也“变了”？因为 `b = a` **没有创建第二个列表**：

```text
a ──┐
    ├────────→ 同一个列表 [10, 20]
b ──┘
```

`append(30)` 修改的是两者共同绑定的**那个列表对象**。列表对象改变了，所以通过 `a` 或 `b` 去读取，都能看到新内容。

请牢牢记住下面的区别：

- `a = 新对象`：通常是在**重新绑定名字**。
- `a.append(...)`：是在**修改列表对象本身**。
- `b = a`：是让 `b` 绑定到 `a` 当前所指的对象，**不是自动复制一个独立副本**。

> 判断两个变量会不会互相影响，不能只看它们的名字，也不能只看有没有 `=`。要问：**它们是否绑定同一个可变对象？发生的是修改对象，还是重新绑定名字？**

## 五、可变与不可变：为什么列表能改，整数和字符串不行？

对象按常见使用方式可以分为两类。

| 类型 | 常见例子 | 能否原地改变对象内容 |
| --- | --- | --- |
| 不可变 | `int`、`float`、`bool`、`str`、`tuple` | 不可以 |
| 可变 | `list`、`dict`、`set` | 可以 |

### 1. 整数相加：重新绑定

```python
a = 5
b = a

a += 1

print(a)
print(b)
```

输出：

```text
6
5
```

整数不可变。这里 `a += 1` 的效果是计算出新的整数结果，然后让 `a` 绑定它；`b` 仍绑定原先的整数。

### 2. 列表追加：原地修改

```python
a = [1, 2]
b = a

a += [3]

print(a)
print(b)
print(a is b)
```

输出：

```text
[1, 2, 3]
[1, 2, 3]
True
```

对普通列表，`+=` 通常执行原地扩展，因此共享同一列表的 `b` 也会看到变化。

### 3. 列表用 `+`：创建新列表

```python
a = [1, 2]
b = a

a = a + [3]

print(a)
print(b)
print(a is b)
```

输出：

```text
[1, 2, 3]
[1, 2]
False
```

因为列表的 `+` 运算产生了**一个新列表**，然后 `a` 绑定到新列表；`b` 仍绑定旧列表。

**同样是加上一个元素，`a += [3]` 与 `a = a + [3]` 对共享列表的影响可以不同。** 这就是为什么理解对象比死记符号更重要。

### 4. 一个容易遗漏的细节：元组

元组自身不可变，但元组里可以包含可变对象：

```python
data = ([1, 2], "完成")
data[0].append(3)
print(data)
```

输出：

```text
([1, 2, 3], '完成')
```

元组的元素绑定关系没有变；变的是**元组内部引用的列表对象**。所以“元组不可变”并不意味着它内部所有对象都永远无法变化。

## 六、`==`、`is` 与 `id()`：相等不代表同一个对象

```python
a = [1, 2]
b = [1, 2]

print(a == b)
print(a is b)
```

输出：

```text
True
False
```

两张内容一样的纸，不代表它们是同一张纸；列表也一样。

- `==` 问：**两个对象的值是否相等？**
- `is` 问：**两个名字现在是否指向完全同一个对象？**

```python
a = [1, 2]
b = a

print(a == b)
print(a is b)
```

这一次两项都是 `True`，因为两个名字绑定同一个列表。

`id(obj)` 返回用于标识对象身份的整数，在对象存活期间保持唯一。但**不要把它理解成一定能看到真实内存地址**，也不要据此推算对象存储细节。

### 为什么不要写 `a is 100`？

某些 Python 实现会复用部分整数或字符串对象，导致一些字面量的 `is` 比较偶尔看起来“也能判断相等”。这不是正确的值比较方式。

一般规则是：

- 比较数值、字符串、列表内容：使用 `==`。
- 判断是否为同一对象：使用 `is`。
- 判断是否为 `None`：通常使用 `is None`。

```python
result = None

if result is None:
    print("还没有结果")
```

## 七、复制列表：浅拷贝与深拷贝到底差在哪里？

如果不希望两个名字共享同一个外层列表，可以创建副本：

```python
a = [10, 20]
b = a.copy()

a.append(30)

print(a)
print(b)
```

输出：

```text
[10, 20, 30]
[10, 20]
```

`a.copy()` 创建了**新的外层列表对象**，所以 `a.append(30)` 不影响 `b`。

但如果列表里面还嵌套一个列表呢？

```python
a = [[1, 2], [3, 4]]
b = a.copy()

a[0].append(99)

print(a)
print(b)
```

输出：

```text
[[1, 2, 99], [3, 4]]
[[1, 2, 99], [3, 4]]
```

原因是：`copy()` 只复制了**外层容器**；其中的子列表仍是共同引用的对象。这叫**浅拷贝**。

需要递归复制内部对象时，可以考虑 `copy.deepcopy()`：

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)

a[0].append(99)

print(a)
print(b)
```

输出：

```text
[[1, 2, 99], [3, 4]]
[[1, 2], [3, 4]]
```

深拷贝会递归处理嵌套对象，但并非所有特殊对象都可以或需要完全复制。普通学习场景下，记住：**赋值不复制；浅拷贝复制外层；深拷贝进一步处理嵌套对象**，就足够了。

## 八、函数传参：为什么函数里修改列表会影响外面？

先看最简单的函数：

```python
def change_number(x):
    x = 100
    print("函数内部：", x)

number = 10
change_number(number)
print("函数外部：", number)
```

输出：

```text
函数内部： 100
函数外部： 10
```

调用时，形参 `x` 最初绑定到调用者传入的那个对象。执行 `x = 100` 后，只是让**函数内部的局部名字 `x`** 改绑到别的对象；函数外的 `number` 没变。

再看列表：

```python
def add_score(items):
    items.append(100)

scores = [80, 90]
add_score(scores)
print(scores)
```

输出：

```text
[80, 90, 100]
```

这次函数没有重新绑定外部名字，而是通过形参 `items` **修改了共享列表对象**，所以调用者能看到变化。

可以把传参理解为：**调用函数时，形参名绑定到实参表达式求得的对象**。常见说法是“对象共享传递”（call by sharing）。它既不是“复制整个对象”，也不是“函数能够随意改写外部变量名”。

### 小心可变默认参数

错误示范：

```python
def collect(value, items=[]):
    items.append(value)
    return items

print(collect(1))
print(collect(2))
```

输出：

```text
[1]
[1, 2]
```

为什么第二次不是 `[2]`？因为默认参数表达式在**函数定义执行时求值一次**，之后未传该参数的调用会复用同一个列表。

更稳妥的写法：

```python
def collect(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items

print(collect(1))
print(collect(2))
```

输出：

```text
[1]
[2]
```

## 九、作用域：Python 去哪里寻找一个变量名？

为什么函数里有的变量可以读取，有的却报错？因为**名字并不是在程序的任何位置都能直接访问**。

### 1. 全局和局部

```python
school = "第一中学"

def introduce():
    student = "小明"
    print(school)
    print(student)

introduce()
```

函数内部可以读取模块层定义的 `school`；`student` 则是函数中的局部名字。直接在函数外执行 `print(student)` 会产生 `NameError`（假定外部没有另外定义同名变量）。

### 2. 为什么读得了，却不能随便先读取再赋值？

```python
count = 10

def add_one():
    count = count + 1

add_one()
```

这段代码会发生 `UnboundLocalError`。原因不是 Python 找不到模块层的 `count`，而是函数体对 `count` 有赋值，Python 因而把它认定为**本函数的局部名字**；右侧读取发生时，该局部名字还没有值。

对零基础读者来说，更清楚、也更推荐的做法是**传入数据，再返回结果**：

```python
def add_one(count):
    return count + 1

count = 10
count = add_one(count)
print(count)
```

输出：

```text
11
```

这段程序的数据从哪里来、到哪里去，都一目了然。

### 3. 什么是 LEGB？

Python 常见的名字查找规则可以简记为 **LEGB**：

| 层级 | 英文 | 简单理解 |
| --- | --- | --- |
| L | Local | 当前函数内部 |
| E | Enclosing | 外层函数内部 |
| G | Global | 当前模块顶层 |
| B | Built-in | Python 内置名称，如 `print` |

例如：

```python
name = "全局"

def outer():
    name = "外层"

    def inner():
        print(name)

    inner()

outer()
```

输出：

```text
外层
```

因为 `inner` 自己没有名为 `name` 的局部绑定，会继续到外层函数中寻找，并在那里找到。

如果确实需要在函数里重新绑定模块级变量，可学习 `global`；要重新绑定外层函数的局部变量，可学习 `nonlocal`。但初学阶段，优先使用参数和返回值，通常更容易排查错误。

## 十、变量名怎么写？哪些习惯值得从一开始养成？

以下是合法的变量名：

```python
score = 95
student_name = "小明"
total_2026 = 100
_private_value = 1
```

以下写法不合法：

```python
# 2score = 95     # 不能以数字开头
# student-name = "小明"  # 连字符会被解释为减号
# class = 1       # class 是关键字
```

变量名区分大小写，所以 `score` 与 `Score` 是不同名字。Python 也支持部分非 ASCII 字符作为标识符，但为了项目协作和跨环境兼容，日常代码通常优先使用有意义的英文名称。

推荐遵守这些习惯：

- 用小写字母和下划线命名，例如 `student_score`。
- 名字应说明用途，避免到处使用 `a`、`b`、`x`。
- 不要把变量命名成 `list`、`str`、`print` 等常用内置名称，以免遮蔽原功能。
- 约定用全大写表示常量，例如 `MAX_SCORE = 100`，但这**只是约定，不会让 Python 自动禁止修改**。

### 类型注解是不是强制规定类型？

```python
value: int = 10
value = "现在是字符串"
print(value)
```

输出：

```text
现在是字符串
```

通常情况下，`: int` 是**类型注解**，帮助阅读和静态检查工具理解代码，并不会自动强制运行时只能绑定整数。这与一些静态类型语言的变量声明不同。

## 十一、删除变量名和垃圾回收是一回事吗？

```python
a = [1, 2]
b = a

del a

print(b)
```

输出：

```text
[1, 2]
```

`del a` 删除了当前位置中名字 `a` 的绑定；但 `b` 仍然绑定到那个列表，所以列表仍然可以使用。

当某个对象不再可达时，Python 运行时可能回收它占用的资源。具体回收时机和机制与实现有关；不能把 `del` 简单理解为“立即把对象从内存里删除”。

## 十二、常见错误速查：先识别原因，再动手改

| 现象 | 常见原因 | 处理思路 |
| --- | --- | --- |
| `NameError` | 使用了当前查找范围中未定义的名字 | 检查拼写、定义顺序、作用域 |
| `UnboundLocalError` | 函数内局部变量在绑定前被读取 | 检查局部赋值；优先传参与返回 |
| 两个列表“一起变” | 两个名字绑定到同一个可变列表 | 需要独立对象时显式复制 |
| `==` 为真，`is` 为假 | 内容相等，但不是同一个对象 | 按需求选择值比较或身份比较 |
| 复制后内部列表仍一起变 | 使用了浅拷贝 | 检查嵌套共享，必要时深拷贝 |
| 每次调用函数结果累积 | 可变默认参数被复用 | 使用 `None` 默认值并在函数内新建 |

## 十三、动手练习：先猜输出，再运行验证

建议不要急着看解析。真正理解变量的最好办法，是**能说清每次绑定和修改发生在哪里**。

### 练习 1：赋值和读取

```python
x = 3
y = x
x = x + 4

print(x)
print(y)
```

**答案：** `7` 和 `3`。`x = x + 4` 重新绑定 `x`，不会修改 `y` 的绑定。

### 练习 2：两个列表

```python
a = [1, 2]
b = a
b.append(3)

print(a)
print(a is b)
```

**答案：** `[1, 2, 3]` 和 `True`。`a`、`b` 共享同一列表，`append` 修改这个列表。

### 练习 3：看出 `+` 与 `+=` 的区别

```python
a = [1]
b = a
a = a + [2]
b += [3]

print(a)
print(b)
```

**答案：** `[1, 2]` 和 `[1, 3]`。`a = a + [2]` 让 `a` 绑定到新列表；`b += [3]` 修改的是 `b` 原先绑定的旧列表。

### 练习 4：字符串与变量

```python
name = "小明"
score = 88

print("name")
print(name)
print(f"{name}：{score}分")
```

**答案：**

```text
name
小明
小明：88分
```

第一行是普通字符串；第二行读取变量；第三行使用 f-string 插入表达式的值。

### 练习 5：函数会修改外部数据吗？

```python
def update(items):
    items.append(4)
    items = [9]
    return items

numbers = [1, 2]
result = update(numbers)

print(numbers)
print(result)
```

**答案：** `[1, 2, 4]` 和 `[9]`。函数先修改共享列表，再让局部名字 `items` 指向一个新列表；这一步不会重新绑定外部的 `numbers`。

## 十四、把整篇文章串起来：遇到变量题就问五个问题

看到稍复杂的代码，可以按下面的顺序分析：

1. **右侧先算出了什么对象？** 是整数、字符串、列表，还是表达式结果？
2. **哪个名字绑定了它？** 是否有重新赋值？
3. **两个名字是否指向同一对象？** 特别注意 `b = a`。
4. **代码是在修改对象，还是重新绑定名字？** 特别注意 `append`、`+=` 和 `+`。
5. **名字在哪个作用域中被读取？** 是局部、外层函数、全局，还是内置名称？

最后用一段小程序复习全文：

```python
scores = [80, 90]
backup = scores

scores = scores + [95]
backup.append(100)

print("scores:", scores)
print("backup:", backup)
print("同一对象吗？", scores is backup)
```

输出：

```text
scores: [80, 90, 95]
backup: [80, 90, 100]
同一对象吗？ False
```

**逐步理解：**

1. `scores` 先绑定到列表 `[80, 90]`。
2. `backup = scores` 让两个名字共享该列表。
3. `scores = scores + [95]` 创建一个新列表，只有 `scores` 改绑。
4. `backup.append(100)` 修改旧列表，`backup` 仍指向它。
5. 因为两者已经是不同的列表对象，所以 `scores is backup` 为 `False`。

**这就是 Python 变量最核心的原理：对象可以被多个名字共享；赋值改变绑定，原地操作改变对象。** 一旦弄明白这两种变化的区别，后面的列表、函数、字典、面向对象编程都会更容易理解。

Python 常见符号详解：从括号到运算符

刚开始学习 Python 时，代码里经常会出现各种符号，例如 "()"、"[]"、"{}"、":"、"=" 和 "=="。

这些符号看起来很简单，但它们决定了代码如何组织、数据如何存储，以及程序如何进行判断和计算。

本文按照实际使用场景，把 Python 常见符号分成几个类别，通过简短示例和运行结果，帮助初学者建立清晰的认识。

一、三种常见括号

圆括号、方括号和花括号是 Python 中最容易混淆的三种符号。

符号| 常见作用| 示例
"()"| 调用函数、组织表达式、创建元组| "print("Hello")"
"[]"| 创建列表、访问元素、切片| "scores[0]"
"{}"| 创建字典、集合，或在 f-string 中插入变量| "{"name": "小明"}"

1. 圆括号 "()"

圆括号最常见的用途是调用函数。

print("Hello Python")
len("Python")

- "print()"：输出内容。
- "len()"：获取字符串、列表等对象的长度。
- "()" 还可以用于控制计算顺序。

例如：

result = (2 + 3) * 4
print(result)

输出：

20

圆括号也可以创建元组：

point = (3, 5)

注意：只有一个元素的元组需要在元素后面加逗号，例如 "(3,)"。

2. 方括号 "[]"

方括号常用于列表和元素访问。

scores = [88, 92, 76]

print(scores[0])
print(scores[1])

输出：

88
92

Python 的列表索引从 "0" 开始，因此 "scores[0]" 表示第一个元素。

方括号还可以用于修改列表元素：

scores[0] = 95
print(scores)

输出：

[95, 92, 76]

也可以使用切片获取一部分数据：

print(scores[0:2])

输出：

[95, 92]

这里的 "0:2" 表示从索引 "0" 开始，取到索引 "2" 之前，不包含索引 "2"。

3. 花括号 "{}"

花括号常见于字典、集合和 f-string。

字典：保存键和值之间的对应关系。

student = {
    "name": "小明",
    "score": 92
}

print(student["name"])

输出：

小明

集合：保存不重复的元素。

numbers = {1, 2, 2, 3}
print(numbers)

集合中重复的元素会被去重。

注意：空的 "{}" 创建的是空字典，而不是空集合。创建空集合需要使用 "set()"。

f-string：在字符串中插入变量。

name = "小明"
score = 92

print(f"{name}的成绩是{score}分")

输出：

小明的成绩是92分

这里的花括号表示需要读取并显示变量的值。

二、冒号、逗号和点号

这三个符号在 Python 代码中出现频率很高，尤其是在列表、条件判断、循环和函数调用中。

1. 冒号 ":"

冒号通常有两个重要用途。

用途一：引出代码块。

score = 92

if score >= 60:
    print("考试通过")

"if" 条件后面的冒号表示条件判断的代码块从下一行开始。

冒号后面通常需要换行，并使用缩进表示代码块的范围。

用途二：分隔数据或指定切片范围。

student = {"name": "小明", "score": 92}

numbers = [10, 20, 30, 40]
print(numbers[1:3])

输出：

[20, 30]

在字典中，冒号分隔键和值；在切片中，冒号分隔起始索引和结束索引。

2. 逗号 ","

逗号用于分隔多个数据或参数。

name = "小明"
age = 18

print(name, age)

输出：

小明 18

逗号还可以分隔列表元素：

scores = [88, 92, 76]

以及函数参数：

print("成绩：", 92)

注意：逗号不只是排版符号。在 Python 中，逗号还可以用于构造元组，例如 "point = 3, 5"。

3. 点号 "."

点号常用于访问对象的属性或方法。

name = "python"

print(name.upper())
print(name.capitalize())

输出：

PYTHON
Python

其中：

- "name"：字符串变量。
- ".upper"：字符串对象提供的方法。
- "()"：调用这个方法。

再看一个列表示例：

scores = [88, 92]

scores.append(95)
print(scores)

输出：

[88, 92, 95]

"append()" 是列表提供的方法，用于在列表末尾添加元素。

可以简单记住：点号用于访问，圆括号用于调用。

三、等号与比较符号

这一类符号尤其重要，因为它们经常出现在变量赋值、条件判断和循环中。

符号| 作用| 示例
"="| 赋值| "score = 92"
"=="| 判断是否相等| "score == 92"
"!="| 判断是否不相等| "score != 60"
">"| 大于| "score > 60"
"<"| 小于| "score < 60"
">="| 大于或等于| "score >= 60"
"<="| 小于或等于| "score <= 100"

重点："=" 和 "==" 不一样

score = 92
print(score == 92)

输出：

True

第一行的 "=" 是把 "92" 赋给变量 "score"。

第二行的 "==" 是检查 "score" 是否等于 "92"。

如果把它们混淆，就很容易写错条件判断。

比较符号经常和 "if" 一起使用

score = 92

if score >= 60:
    print("通过")
else:
    print("未通过")

输出：

通过

比较表达式会得到布尔值："True" 或 "False"，程序再根据结果决定执行哪一段代码。

四、数学运算符号

Python 不仅可以处理数据，还能直接进行数学计算。

符号| 作用| 示例| 结果
"+"| 加法| "3 + 2"| "5"
"-"| 减法| "3 - 2"| "1"
"*"| 乘法| "3 * 2"| "6"
"/"| 除法| "5 / 2"| "2.5"
"//"| 向下取整除法| "5 // 2"| "2"
"%"| 取余数| "5 % 2"| "1"
"**"| 幂运算| "2 ** 3"| "8"

例如：

a = 10
b = 3

print(a + b)
print(a // b)
print(a % b)
print(a ** b)

输出：

13
3
1
1000

其中，"%" 不仅可以参与数学计算，还经常用于判断一个数字是否为偶数。

number = 8

print(number % 2 == 0)

输出：

True

因为偶数除以 "2" 的余数为 "0"。

五、引号、井号与缩进

1. 引号 "' '" 和 "" ""

引号用于表示字符串。

name = "小明"
message = '你好，Python'

print(name)
print(message)

在一般情况下，单引号和双引号都可以创建字符串。

如果字符串内部包含某种引号，可以选择另一种引号：

message = "It's Python"
print(message)

输出：

It's Python

2. 井号 "#"

井号用于编写注释。Python 执行代码时，会忽略注释符号后面的普通注释文本。

# 定义学生成绩
score = 92

print(score)  # 输出成绩

输出：

92

注释可以帮助自己或其他人理解代码的用途。

3. 缩进：不是普通装饰

Python 使用缩进区分代码块，通常使用四个空格。

score = 92

if score >= 60:
    print("通过")
    print("继续努力")

两条 "print()" 语句都属于 "if" 代码块。

如果缩进位置不正确，就可能出现 "IndentationError"，或者让代码的执行逻辑发生变化。

记忆要点：冒号引出代码块，缩进表示代码块的范围。

六、逻辑符号与成员判断

1. "and"、"or"、"not"

这三个是 Python 的逻辑运算符，用于组合或反转条件。

符号| 含义| 示例
"and"| 两个条件都成立| "age >= 18 and score >= 60"
"or"| 至少一个条件成立| "score >= 90 or score < 60"
"not"| 对布尔结果取反| "not (score < 60)"

例如：

age = 18
score = 92

print(age >= 18 and score >= 60)

输出：

True

这里两个条件都成立，因此整个表达式的结果是 "True"。

2. "in"

"in" 用于判断某个元素是否存在于指定的数据中。

scores = [88, 92, 76]

print(92 in scores)
print(60 in scores)

输出：

True
False

这在列表筛选、字符串查找和数据检查中都很常用。

七、其他值得认识的符号

除了上面的基础符号，还有一些常见写法值得了解。

符号| 常见用途| 示例
"+="| 在原值基础上增加后赋值| "score += 5"
"-="| 在原值基础上减少后赋值| "score -= 5"
"\n"| 在字符串中换行| "print("第一行\n第二行")"
"\"| 在字符串中表示转义，也可用于显式续行| ""第一行\n第二行""
"*"| 乘法，也可用于可迭代对象展开等场景| "numbers = [1, 2]"
";"| 在同一行分隔多条简单语句，不推荐日常滥用| "a = 1; b = 2"

例如：

score = 90
score += 5

print(score)

输出：

95

"score += 5" 等价于 "score = score + 5"。

需要注意，符号的具体含义有时取决于使用场景。比如 "*" 在数学表达式中表示乘法，在函数参数和序列操作中还可以有其他用途。初学阶段先掌握最常见的用法即可。

八、最后总结：按类别记忆

学习 Python，不需要一开始就背完所有符号。先理解下面这张速查表，再结合实际代码练习，会更容易掌握。

类别| 需要记住的符号| 核心作用
括号| "()" "[]" "{}"| 函数调用、列表与字典、变量插入
结构| ":" "," "."| 代码块、数据分隔、访问属性和方法
赋值与比较| "=" "==" "!=" ">" "<"|

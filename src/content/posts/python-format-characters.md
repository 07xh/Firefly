# Python 格式字符简短总结

Python 里常说的“格式字符”，最常见的是 `%` 格式化里的占位符，比如 `%s`、`%d`。现在更推荐用 f-string，但读旧代码时仍会经常遇到 `%` 写法。

## 一、% 格式化常用字符

| 格式字符 | 含义 | 例子 |
| --- | --- | --- |
| `%s` | 字符串，也能接收其他类型 | `'%s' % 'Tom'` |
| `%d` | 十进制整数 | `'%d' % 18` |
| `%f` | 浮点数，默认 6 位小数 | `'%f' % 3.14` |
| `%.2f` | 保留 2 位小数 | `'%.2f' % 3.14159` |
| `%x` | 十六进制整数，小写 | `'%x' % 255` |
| `%%` | 输出一个百分号 | `'100%%'` |

示例：

```python
name = '小明'
age = 18
score = 92.5

print('姓名：%s，年龄：%d，分数：%.1f' % (name, age, score))
# 姓名：小明，年龄：18，分数：92.5
```

小提醒：`%s` 比较万能，但类型清楚时用 `%d`、`%f` 可读性更好。

## 二、f-string 更直观

Python 3.6+ 推荐使用 f-string：

```python
name = '小明'
age = 18
score = 92.5

print(f'姓名：{name}，年龄：{age}，分数：{score:.1f}')
# 姓名：小明，年龄：18，分数：92.5
```

花括号里的 `:.1f` 就是格式说明：`.1` 表示保留 1 位小数，`f` 表示按浮点数显示。

`str.format()` 也能实现类似效果：

```python
print('姓名：{}，分数：{:.1f}'.format('小明', 92.5))
# 姓名：小明，分数：92.5
```

## 三、常见格式控制

```python
num = 3.14159

print(f'{num:.2f}')   # 3.14，保留两位小数
print(f'{num:8.2f}')  # 总宽度 8，右对齐
print(f'{num:<8.2f}') # 左对齐
print(f'{num:>8.2f}') # 右对齐
print(f'{num:^8.2f}') # 居中
print(f'{42:05d}')    # 00042，补零到 5 位
print(f'{1234567:,}') # 1,234,567，千位分隔
```

记忆方法：

- `.2f`：小数点后保留 2 位
- `8`：总宽度为 8
- `<`、`>`、`^`：左对齐、右对齐、居中
- `0`：用 0 填充
- `,`：千位分隔

## 四、总结

- 旧代码常见：`%s`、`%d`、`%f`、`%x`、`%%`
- 新代码推荐：f-string，例如 `f'{score:.1f}'`
- 格式说明可粗略理解为：`[填充][对齐][宽度][,][.精度][类型]`
- 先掌握字符串、整数、浮点数、小数位数和宽度对齐，就够日常使用了

> **先修知识**：列表、索引从 0 开始、`len`。先读[列表方法](/posts/python-list-methods-complete-guide/)和[零基索引的原理](/posts/python-zero-based-indexing-deep-dive/)，再进入本篇。

学完这篇文章，你应能不靠猜测判断 `a[1:4]`、`a[-3:]`、`a[::-1]`、`a[5:1:-2]` 的结果，也能区分取切片、修改切片和复制列表。

## 一、最重要的写法：a[start:stop:step]

```python
letters = ["A", "B", "C", "D", "E", "F"]
print(letters[1:4])  # ['B', 'C', 'D']
```

三个部分分别代表：**从哪里开始、到哪里停止（不包括）、每次走几步**。

当步长为正时，可以把元素和**边界**画成这样：

```text
边界： 0   1   2   3   4   5   6
       | A | B | C | D | E | F |
索引：   0   1   2   3   4   5
           └── [1:4) ────┘
```

`a[1:4]` 从边界 1 开始、到边界 4 结束，选出索引 1、2、3 的三个元素。此时长度刚好是 `4-1=3`。这就是**左闭右开**区间的用处。

## 二、不写 start / stop 是什么意思？

```python
a = [10, 20, 30, 40, 50]
print(a[:3])  # [10, 20, 30]
print(a[2:])  # [30, 40, 50]
print(a[:])   # [10, 20, 30, 40, 50]
```

步长默认是 `1`：省略起点，从最前面开始；省略终点，走到末尾。特别注意 `a[:]` 返回一个**新的外层列表**，不等于 `b = a` 指向同一个对象。

## 三、step：为什么隔一个取一个？

```python
a = ["A", "B", "C", "D", "E", "F"]
print(a[0:6:2])  # ['A', 'C', 'E']
print(a[1::2])   # ['B', 'D', 'F']
```

从起点开始每次前进 2 个索引，所以选取 0、2、4，或者 1、3、5。**步长不是取几个元素，而是相邻选中位置的间隔**。

`step=0` 不合法，会触发 `ValueError: slice step cannot be zero`。

## 四、负索引：先把它翻译成实际位置

```text
元素：       A    B    C    D    E    F
正索引：     0    1    2    3    4    5
负索引：    -6   -5   -4   -3   -2   -1
```

```python
a = ["A", "B", "C", "D", "E", "F"]
print(a[-1])   # F
print(a[-3:])  # ['D', 'E', 'F']
print(a[:-2])  # ['A', 'B', 'C', 'D']
```

对长度为 6 的列表，`-3` 对应正索引 3。**负数不是“从右往左自动遍历”，只是用列表末尾作为参照来定位**。取值的走向仍取决于步长。

## 五、负步长：从大索引往小索引走

```python
a = ["A", "B", "C", "D", "E", "F"]
print(a[5:1:-2])  # ['F', 'D']
print(a[::-1])    # ['F', 'E', 'D', 'C', 'B', 'A']
```

`a[5:1:-2]` 的逐步索引是 5、3，然后准备走到 1 时**停止（1 不包含）**。

反向时，省略的默认起点/终点也会跟着方向调整：`a[::-1]` 从最后一个有效元素开始，向左一直取到第一个元素。不要把 `a[::-1]` 简单理解为 `a[0:len(a):-1]`，后者为空。

对比：

```python
print(a[1:5:-1])  # []，方向与区间不匹配
print(a[5:1:-1])  # ['F', 'E', 'D', 'C']
print(a[-1:-4:-1])  # ['F', 'E', 'D']
```

**判断三问**：从哪个实际索引开始？每次加几或减几？有没有越过停止边界？

## 六、为什么空切片不一定报错？

```python
a = [10, 20, 30]
print(a[20:30])  # []
print(a[2:1])    # []
# print(a[20])   # IndexError: list index out of range
```

单个索引必须找到对应元素，超出范围会报错；切片通常会把越界的端点限制在有效边界内，所以可能得到空列表。并不是所有错误都能被切片忽略，例如步长 0 仍会报错。

## 七、切片也能用在字符串和元组上

```python
print("Python"[1:4])      # yth
print((10, 20, 30)[::2])  # (10, 30)
```

字符串与元组支持切片，但**自身不可变**；不能对字符串、元组做切片赋值。

## 八、切片赋值：和“取出一份”不是同一回事

```python
a = [0, 1, 2, 3, 4]
a[1:4] = [10, 20]
print(a)  # [0, 10, 20, 4]
```

没有步长或步长为 1 时，替换的新元素数可以不同，因此列表长度可能变化。扩展切片（步长不为 1）要求左右元素个数相同：

```python
a = [0, 1, 2, 3, 4, 5]
a[::2] = [9, 8, 7]
print(a)  # [9, 1, 8, 3, 7, 5]
```

如果只给两个元素来替换三个位置，Python 会报 `ValueError`。

## 九、复制与引用：切片复制只到第一层

```python
a = [1, 2, 3]
b = a[:]
b[0] = 99
print(a)  # [1, 2, 3]
print(b)  # [99, 2, 3]
```

但嵌套可变元素仍可能共享：

```python
a = [[1], [2]]
b = a[:]
b[0].append(8)
print(a)  # [[1, 8], [2]]
```

`[:]` 是**浅复制**。需要完整独立的嵌套结构时，参考 `copy.deepcopy`。不要误以为切片能彻底复制任意层级数据。

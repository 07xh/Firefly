## 一、评分标准：11分档到底意味着什么

翻译满分15分，11分档的定义：

> **译文基本上表达原文的意思，结构较清晰，语言较流畅，但有少量语言错误。**

- 11分档的实际得分区间：**10～12分**
- 折算成710分制：翻译单项 **≥ 90分**
- 对比：很多人写作 + 翻译加一起才80多分

**关键信息**：不需要满分，只要做到“基本表达意思 + 结构清晰 + 无语言错误”，就能拿高分。

---

## 二、保底第一原则：单词正确

### 核心策略：不会的词就「换一种说法」

翻译中遇到不会写的词，**不要硬写，用你会的词解释出来**。


| 原文       | 高配写法                                | 低配写法（保底）                     |
| -------- | ----------------------------------- | ---------------------------- |
| 匠人       | craftsman                           | worker                       |
| 旅游景点     | tourist attraction                  | a place                      |
| 多元化的生活方式 | diversified lifestyle               | different lifestyle          |
| 摇篮       | cradle                              | the start                    |
| 民营企业     | private enterprise                  | private company              |
| 促进       | promote                             | make...develop fast          |
| 打造       | create/build                        | make                         |
| 民俗文化     | folk culture                        | local culture                |
| 核心竞争力增强  | enhancement of core competitiveness | developing faster and faster |
| 悄然兴起     | emerge quietly                      | become popular               |
| 欣赏       | appreciate                          | enjoy                        |


**黄金法则**：小词不会写，就「装作没看见」，用你会的词把意思解释清楚即可。保证翻译出来的句子**没有任何语法错误**才是第一位的。

---

## 三、保底第二原则：语法正确

### 问题诊断

你写作文时最大的问题：总想「装」——

- 总想写个**定语从句**（非限制性的）让老师表扬
- 总想写个**虚拟语气**震撼灵魂
- 总想写个**倒装**，结果倒得四不像

### 解决方案：不会就别装，全部用简单句

> **写作和翻译的时候，所有写不来的长难句，全部都用简单句来表达。**
> 可能需要两到三个简单句来表达一个长句，没关系，说清楚就好。

#### 实战示例

**原文**：当我进来的时候已经很疲惫了，我看见一个看起来特别像大雁的爷爷，被一群人围着，像鸭子一样在跳舞。

**满分写法**（复杂句）：你写不来的，别试了。

**保底写法**（简单句拆分）：

```
I came in and felt tired.
Then I saw a grandfather.
He looked like a wild goose.
And he was in the center of many people.
He was dancing like a duck.
```

→ 全部初一水平词汇，但**每个句子都没有语法错误**，翻译分照样不低。

#### 实战示例2

**原文**：民营企业核心竞争力的增强，为中国经济的高质量发展提供了有力支撑。

**保底写法**：

```
Private companies are developing faster and faster.
As a result, they supported Chinese economy's development a lot.
```

→ 两个简单句搞定，意思表达清楚，没有语法错误。

### 简单句都写不对怎么办？

刘晓艳原话：去微信公众号「**小燕工作室**」找简单句讲解视频（约3小时），听两遍再去写作文和翻译，会非常舒服。

## 四、高分进阶：语言正确 + 多变 + 逻辑清晰

保底够了，想冲更高分？做到三点：

### 1. 语言正确多变

**单词多变**：同一个单词不要反复使用。


| 你常写的          | 替换一下                                       |
| ------------- | ------------------------------------------ |
| think         | argue / believe / hold the view that       |
| people        | the young and old / citizens / individuals |
| more and more | an increasing number of                    |
| important     | vital / essential / significant            |


**语法多变**：一篇作文里要有——


| 结构   | 你目前只有 | 应该还有        |
| ---- | ----- | ----------- |
| 句子类型 | 简单句   | + 并列句 + 复合句 |
| 语序   | 正常语序  | + 倒装        |
| 语态   | 主动    | + 被动        |


### 2. 逻辑关系清晰

句子之间必须有**逻辑关系词**，不能只用 and / but / so。

→ 详见第八节「逻辑关系词替换表」。

## 五、核心句型一：被动语态

### 写作中什么时候用被动？

> **只要作文中见到「人」做主语，都可以考虑写成被动。**

注意：不要写太多，**一篇作文用2次足够**。

#### 示例1（四级写作真题）

原文：大学生应该利用学校资源发展自己的学术能力。

- 主动写法（你通常写的）：University students should use on-campus resources to develop their academic abilities.
- **被动写法**：On-campus resources can be used to develop students' academic abilities.

#### 示例2

原文：人们普遍认为健身已经成为一种流行趋势了。

- 低配主动：Many people think that fitness has become a popular trend.
- **被动写法**：Fitness is argued to be a popular trend among the young and old.

### 翻译中什么时候用被动？

> **根据原文来——原文有被动含义就写被动，没有就不写。**（跟写作不同，翻译是被动句你就翻被动。）

#### 示例（翻译真题）

原文：井冈山……因其辉煌历史**被誉为**中国革命的红色摇篮。

```
Jinggangshan is between Hunan province and Jiangxi province.
Because of its history, it is called the start of Chinese revolution.
```

→ 「被誉为」= is called，天然被动。

#### 示例

原文：目前这项技术已经在许多国家**得到了广泛的应用**。

```
At present, this technology has been widely used in many countries.
```

→ 「得到了应用」= has been used，天然被动。

## 六、核心句型二：非谓语动词

### 什么时候用非谓语动词？

> **作文或翻译的时候，只要见到前后两句话的主语是一致的，都可以把其中一句话写成非谓语动词。**（一般把后面那句改成 -ing 形式。）

#### 示例1

原文：我爱你，我要你成为这个世界上最幸福的人。

- 你的写法：I love you. I want you to become the happiest person in the world.
- **非谓语写法**：I love you, wanting you to become the happiest person in the world.

#### 示例2（翻译真题）

原文：绿水青山促进了当地的旅游，创造了可观的经济效益。

→ 主语都是「绿水青山」，前后一致。

```
The green mountains and clear waters have made tourism there fast,
bringing much money for the local people.
```

#### 示例3（翻译真题）

原文：哈尔滨利用丰富的冰雪资源，打造了极具地方特色的冰雪大世界，让游客在欣赏冰雪美景的同时还能体验民俗文化。

→ 主语都是「哈尔滨」。

```
Harbin uses its ice and snow to create a special ice and snow world,
allowing tourists to enjoy the beauty of ice and snow and experience local culture.
```

#### 示例4

原文：近年来，城市漫步在中国年轻人中悄然兴起，已经成为一种旅游新潮流。

→ 主语都是「城市漫步」。

```
In recent years, city walk has become popular among young people,
becoming a new travel trend.
```

## 七、核心句型三：并列句与逻辑关系词

并列句的关键不在「并列」，而在**逻辑关系词**。用好逻辑关系词，即使全是简单词、简单句，作文也能蓬荜生辉。

---

## 八、逻辑关系词替换表（必背）

### ① 表示原因（背2个）


| 低级（别再用了）   | 高级替换          |
| ---------- | ------------- |
| because    | **in that**   |
| because of | **thanks to** |


> 例：Thanks to your help, I passed CET-4.

### ② 表示结果（背2个）


| 低级  | 高级替换                                                                       |
| --- | -------------------------------------------------------------------------- |
| so  | **thereby** / **consequently** / **in consequence** / **as a consequence** |


> 例：I was absent as a consequence.

### ③ 表示并列/递进（背2个）


| 低级  | 高级替换                                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------- |
| and | **likewise** / **similarly** / **equally** / **simultaneously** / **at the same time** / **in the meanwhile** |


> 例：I love Liu Xiaoyan. Likewise, Liu Xiaoyan loves me.

### ④ 表示转折（背2个）


| 低级  | 高级替换                                                                           |
| --- | ------------------------------------------------------------------------------ |
| but | **by contrast** / **conversely** / **on the contrary** / **on the other hand** |


### ⑤ 表示递进（背1个）


| 低级   | 高级替换                                             |
| ---- | ------------------------------------------------ |
| then | **in addition** / **moreover** / **furthermore** |


### ⑥ 表示引出话题/对象（背1个）

文章开头引出讨论对象时用：

- **with regard to...** / **concerning...** / **as for...**

> 例：With regard to filial piety, my view is...

### ⑦ 表示总结（背1个）


| 低级（别再用了）   | 高级替换                                                                    |
| ---------- | ----------------------------------------------------------------------- |
| all in all | **on the whole** / **in summary** / **substantially** / **in any case** |


> 关于 all in all：在它后面写个小括号，写个「吐」，然后呸——吐它一口。初高中用得太熟的词，改卷老师看了都恶心。

## 九、总结速查卡

### 翻译 &amp; 写作保底三步

```
第1步：单词不会写 → 用简单词解释，保证不出错
第2步：长句写不来 → 拆成2-3个简单句，保证语法正确
第3步：句子之间 → 加上高级逻辑关系词（替换 and/but/so）
```

### 高分加分项（每项用1-2次即可）

```
✓ 被动语态（人做主语时考虑变被动）
✓ 非谓语动词（前后主语一致时，后句改 -ing）
✓ 并列句 + 高级逻辑关系词
```

### 背诵清单


| 类别   | 必背数量 | 具体词汇                    |
| ---- | ---- | ----------------------- |
| 因为   | 1个   | in that                 |
| 多亏   | 1个   | thanks to               |
| 所以   | 2个   | thereby, consequently   |
| 并且   | 2个   | likewise, similarly     |
| 但是   | 2个   | by contrast, conversely |
| 而且   | 1个   | moreover / furthermore  |
| 引出话题 | 1个   | with regard to          |
| 总之   | 1个   | on the whole            |


**共计：11个词组，足以让写作翻译多考3～4分。**

### 最后的忠告

> 即使你单词很简单，全是简单句，只要句子和句子之间用的逻辑关系词非常高端大气上档次，你的作文和翻译依然可以考很高的分数。

## 学序能做什么？

学序是 Windows 上的多学习平台桌面客户端。如果课程散落在知到、雨课堂、学习通和 U 校园，学序把它们放在同一个导航里：从左侧选择平台，再进入课程、章节、任务或对应平台的设置页面。

它**不是把所有平台的账号合并成一个账号**。每个平台仍需要独立登录，数据读取和可用功能也要按平台确认。

## 主要功能

### 多平台统一入口

左侧是统一导航，课程列表、章节结构、错误提示和状态显示尽量保持一致。无需分别记住几个桌面程序的入口。知到与雨课堂原有业务模块通过独立的 Python 进程保留，不会因换 UI 就删掉旧功能。

### 课程与章节

- **知到**：提供登录、课程列表、共享课程视频与知识点明细、单课或全量只读核验入口。
- **长江雨课堂**：包含会话配置、连接检查、章节与视频元数据读取及原有参数管理。
- **学习通**：独立的课程、章节与任务入口，实际返回与完成状态需要真实账号校验。
- **U 校园**：正在进行课程、单元与资源的接入，不能把本机练习结果当作官方学习记录。

### 进度与运行记录

客户端把不同来源的信息分开：**播放器的位置**、**本机任务是否在运行**、**平台返回的进度**、**最近一次服务器核验结果**。这让用户知道自己看到的是本机状态还是平台已经确认的记录。

## 如何使用

1. 安装 Windows 测试版，在侧边栏选择需要使用的学习平台。
2. 在该平台自己的账号设置里完成连接，再进入课程与章节页面。
3. 遇到课程数据不同步，先检查该平台的连接与服务器核验状态，而不是仅凭播放器或日志里的数值判断完成情况。

## 当前状态

客户端的统一界面和适配架构已有实现。**不同平台的真实登录、课程读取和服务器进度验收尚未全部完成**，不能因 Windows 安装包成功构建就宣称四个平台都完全可用。本项目是第三方个人工具，并非这些学习平台的官方客户端。
